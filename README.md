# Invext

Controle financeiro pessoal: entradas e contas fixas, gastos variáveis, sobra acumulada, investimentos, projetos com projeção e notificações.

**Abrir o app:** https://henriqueruher.github.io/invext/

- Funciona offline e pode ser instalado na tela inicial (Android: menu ⋮ → *Instalar app*; iPhone: Safari → Compartilhar → *Adicionar à Tela de Início*).
- Os dados ficam **só no seu aparelho**. Nada é enviado para servidor nenhum. Use *Ajustes → Exportar* para fazer backup.
- Opcional: proteger os dados com senha (AES-256-GCM, chave derivada por PBKDF2-SHA256 com 600 mil iterações).
