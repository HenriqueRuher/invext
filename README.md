Controle financeiro pessoal: entradas e contas fixas, gastos variáveis, sobra acumulada, investimentos, projetos com projeção e notificações.

## 📲 [Baixar / abrir o Invext](https://henriqueruher.github.io/invext/)

**https://henriqueruher.github.io/invext/**

### Como instalar no celular

**Android (Chrome)**
1. Abra o link acima no celular.
2. Toque no menu **⋮** (canto superior direito).
3. Toque em **Instalar app** (ou *Adicionar à tela inicial*).

**iPhone (Safari)**
1. Abra o link acima no **Safari**.
2. Toque em **Compartilhar** (quadrado com seta para cima).
3. Toque em **Adicionar à Tela de Início**.

O ícone do Invext aparece junto dos outros apps e funciona mesmo sem internet.

### Seus dados

- Ficam **só no seu aparelho**. Nada é enviado para servidor nenhum.
- Faça backup em *Ajustes → Exportar* e guarde o arquivo no Drive ou nos Arquivos.
- Opcional: proteja os dados com senha em *Ajustes → Senha* (AES-256-GCM, chave derivada por PBKDF2-SHA256 com 600 mil iterações). Sem a senha, os dados não podem ser recuperados.
